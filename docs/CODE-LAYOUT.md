# Code Layout (authoritative)

This file overrides the layouts in `docs/requirements/06-architecture-data-model.md`
section 1 and `docs/design/02-architecture-overview.md` section 3, which
disagreed on crate names. Decision record: `docs/adr/0001-code-layout.md`.

## Tree

```
homeoclinic/
  apps/desktop/
    src/                    React UI, one folder per use case (see below)
    src-tauri/              Tauri 2 shell, capabilities, command registration
  crates/
    hc-domain/              entities, value types, validation; NO IO
    hc-storage/             SQLCipher, migrations, repositories, audit, backup
    hc-search/              patient search, phonetic keys, ranking, filters
    hc-repertory/           packs, channels, rubric search, scoring, citations, MM
    hc-licence/             licence verify, identity lock, clock guard, QR, offers
    hc-docs/                print/PDF rendering
    hc-app/                 use-case services + typed Tauri commands
  tools/
    vendor-licence-tool/    offline signer (internal, never shipped)
    content-builder/        source import -> signed .hcpack
    seed/                   synthetic data generator
  tests/
    e2e/                    WebdriverIO + tauri-driver specs, pages/, index.json
    perf/                   NFR harness, baseline.json
  content-sources/          REGISTRY.md, public/, internal-eval/ (data not pushed)
  docs/
    requirements/ design/ ui/ rules/ adr/ task-tracker/
  hc-agents/                AI agent pack
  services/licence-server/  MVP2
  web/portal/               MVP2
```

## Crate dependency rule

```
hc-domain  <-  hc-storage  <-  hc-search
hc-domain  <-  hc-repertory
hc-domain  <-  hc-licence
hc-domain  <-  hc-docs
all of the above  <-  hc-app  <-  apps/desktop/src-tauri
```

No other edges. `hc-domain` depends on no workspace crate. Cycles are a
build failure (checked in CI with `cargo metadata`).
